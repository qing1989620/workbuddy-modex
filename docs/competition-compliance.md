# Competition Compliance (v1.0, Layer 1)

## Modes
- **LIVE**: contest in progress. `internet_rule` may forbid current-contest
  solution/answer/discussion content — enforced by `check_query_allowed`
  (search gate). Allowed: official rules, academic literature, government/
  official statistics, public scientific databases, documentation, historical
  background.
- **TRAINING / REVIEW / RESEARCH**: past papers/solutions may be studied WITH
  attribution; LIVE gate excludes current-year/current-problem material.

## Profile
`state/competition-profile.yaml` (schema: `schemas/competition-profile.schema.json`)
is generated by `ommw competition` (heuristic detect) and MUST be verified
against fetched official rules (`official_sources` + `verification_date` +
rules cache with URL/hash/time, Rule 134). Never trust model memory for rules.

## Page budget
`effective_page_limit`: official rule > user preference > OMMW default. No
hardcoded "30-40 pages".

## AI usage
`state/ai_usage.jsonl` records every AI-assisted step (tool/model/version/time/
task/purpose/categories/human_review/verification/accepted/modified).
`ommw ai-report` generates the paper's AI declaration + `AI工具使用详情.md`
from the ACTUAL ledger. `compliance_gate` fails if the profile requires a
declaration and none exists.

## Gates
`ommw judge` = compliance_gate (page limit, anonymization, AI declaration,
forbidden submission files) + research_verify. No CRITICAL/HIGH -> pass.
Internal review only; not an official scoring model.

## Commands
```
ommw competition -p <proj> --text "..." [--live]
ommw audit-data -p <proj>
ommw ai-report -p <proj>
ommw judge -p <proj>
ommw package -p <proj>
```
