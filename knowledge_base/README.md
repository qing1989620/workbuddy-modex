# Knowledge Base

Purpose: learn METHODS from past work — never copy text. Structure:

```
knowledge_base/
├── award_papers/          # structured knowledge extracted from allowed past papers
├── problem_patterns/      # problem characteristics -> model families
├── model_patterns/        # when_to_use / when_not_to_use / failure modes
├── data_patterns/         # data shapes -> audit/transform guidance
├── experiment_patterns/   # experiment designs per problem family
├── visualization_patterns/# figure types that answer which question
├── paper_patterns/        # structure that serves the evidence
├── abstract_patterns/     # how strong abstracts are built (not copied)
├── innovation_patterns/   # real differences that earned credit
├── reviewer_comments/     # what judges criticized / rewarded
└── failure_cases/         # anti-patterns that lost points
```

Rules:
- NEVER copy sentences/figures from award papers into a new paper.
- LIVE contest mode EXCLUDES current-year/current-problem material (hard gate).
- Retrieval is progressive: load only what the current question needs.
- Every entry records its source + verification status.
